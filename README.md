## 🚀 Meu maior projeto

# 🎲 RPG Phantom Trupe

> **Uma plataforma web criada para auxiliar e centralizar a experiência de uma campanha de RPG.**

O **RPG Phantom Trupe** funciona como um hub para gerenciamento e interação com elementos da campanha, reunindo recursos como **fichas de personagens, NPCs e informações da campanha** em um único ambiente.

O sistema também possui integração com **Discord**, utilizando os cargos do servidor para controlar o acesso dos jogadores.

Além disso, a plataforma conta com recursos voltados para as sessões de RPG, incluindo uma **"Call da Mesa"**, permitindo que os jogadores entrem em uma chamada de voz diretamente pelo site, com suporte a câmera e transmissão de tela.
