# 🚀 Projeto em destaque

<div align="center">

## 🎲 RPG Phantom Trupe

**Uma plataforma web criada para centralizar e aprimorar a experiência de uma campanha de RPG.**

</div>

O **RPG Phantom Trupe** é um projeto desenvolvido para reunir diferentes recursos de uma campanha de RPG em uma única plataforma.

Entre os recursos do sistema estão:

* 🧙 **Fichas de personagens**
* 👤 **NPCs**
* 📖 **Informações da campanha**
* 🔐 **Controle de acesso integrado ao Discord**
* 🎙️ **Call da Mesa**
* 📹 **Suporte para câmera**
* 🖥️ **Transmissão de tela**
* 🌐 **Interface web própria**

A ideia é transformar o site em um verdadeiro **hub digital para a campanha**, permitindo que os jogadores encontrem as informações e ferramentas necessárias em um único lugar.
